# 三维模型标注交互原型

**PROTOTYPE：用于验证交互，尚未作为公开组件 API。**

验证问题：教师能否点击模型表面添加“锚点＋引线＋文字”标注，并在旋转、遮挡和逐条讲解中清楚地展示它？

## 运行

首次安装仓库依赖：`npm install`。

在仓库根目录运行：

```sh
npm run prototype:annotations
```

打开 <http://127.0.0.1:5174/?variant=A>。

| 布局 | URL | 重点 |
| --- | --- | --- |
| A：侧栏编辑 | `?variant=A` | 准备课程、添加及修改标注 |
| B：课堂展示 | `?variant=B` | 大画布与浮动讲解说明 |
| C：逐条讲解 | `?variant=C` | 讲解点列表、单点展示和自动观察视角 |

底部箭头或键盘左右键切换布局；输入文本时不会抢占方向键。切换布局保留当前内存状态。

## 体验顺序

1. 点击“添加三维标注”，再点击心脏模型表面；输入名称和课堂说明。
2. 拖动旋转模型，滚轮缩放；观察锚点跟随部位，文字保持正向可读。
3. 点击“背面”：正面的标注默认被模型遮挡而隐藏；勾选“显示背面标注”比较淡化显示效果。
4. 在 A 中修改名称和说明，或删除当前标注。
5. 在 B 中点击画布标注查看说明；在 C 中逐条切换，观察自动取景是否合适。
6. 点击“标注数据”，修改 JSON 后应用；点击“导出 JSON”获取当前数据。
7. 点击“导入 GLB”，选择自己的未压缩静态 GLB；新模型从空标注开始。点击“恢复示例”重新载入示例模型及三个标注。
8. 展开“完整交互状态”，检查模式、选中 ID、相机、网格列表、遮挡状态和完整标注数据。

标注使用网格局部坐标。更换模型后数据不可直接复用；JSON 回填校验模型名称与网格键。

## 本轮观察

已在真实浏览器中确认：

- 表面点击产生局部位置、法向量和网格键，新增标注可显示与编辑。
- 旋转改变相机视角，保留原有锚点数据。
- 背面观察时，三个正面示例标注隐藏；可切换为淡化显示。
- JSON 回填、导出、布局切换、讲解点选择、GLB 导入和恢复示例可用。
- 390px 手机视口未出现横向溢出。
- `npm run type-check` 通过。

待使用者体验后确定：三种布局如何组合；遮挡默认策略是否合适；密集标注是否需要更好的排布；自动观察视角是否符合课堂习惯。

## 原型边界

- 状态在内存中，刷新页面会重置；导出 JSON 是手动保存方式。
- 文字及引线使用三维位置投影到 HTML/SVG 的方式呈现，并非立体文字网格。
- 首轮验证静态、未压缩的 GLB；没有配置 Draco/KTX2 解码器，也未验证骨骼动画和变形网格的锚点。
- 心脏资产是本仓库原创的简化交互示意模型，按 MIT 授权；课堂内容与模型精度尚未验收。
- 文件位于 `src/prototype/`，独立开发入口；不从库入口导出。

运行 `python3 src/prototype/generate-heart-prototype.py` 可重新生成内置资产。GLB 结构参考 [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)。

## 保存方式

原型位于 `prototype/model-annotations` 分支。最终布局和交互的选择尚待用户反馈；正式实现应根据验收后的决策重新编写。
