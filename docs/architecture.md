# 三维教学标注组件结构

`src/index.ts` 导出 `ModelAnnotationViewer` 和模型、锚点、标注、错误、加载事件及组件 ref 类型。README 是公开接入约定；原有学科组件保留原入口。

## 数据与交互

`ModelAnnotationViewer.vue` 管理模型加载反馈、添加草稿、选择、A 侧栏、课堂展示和公开绑定。模型与标注使用命名 v-model；组件编辑时创建新集合，不写入宿主对象。未绑定时状态保留在组件内存，存储由宿主管理。

公开 ref 只提供 `resetView()` 和 `focusAnnotation(id)`；加载、错误和选择通过事件通知宿主。侧栏隐藏时保留创建与画布选择，通过下方详情展示说明；组件内修改、删除入口仅在编辑模式的侧栏出现。`present` 约束组件内写操作，宿主仍可更新公开输入。

`data.ts` 检查标注数据：模型 ID、唯一 ID、稳定节点路径、有限坐标、非零法向量及文本字段。展示过滤无效数据并发出错误，不自动改写宿主存档。

`ModelScene.ts` 封装 GLB 加载、取景、OrbitControls、表面射线选取和标签投影。节点路径由 glTF 场景子节点索引生成；锚点保存网格局部坐标及局部法向量。相同结构重新加载可以恢复，与 URL、名称和运行时 UUID 无关；模型版本变更由宿主换 ID。

加载边界是静态、未压缩 GLB 2.0。URL 通过 fetch 读取，关联资源相对于 URL 解析；File 在浏览器读取，本地输入包含外链 buffer 或纹理时拒绝加载，需内嵌资源。模型动画、骨骼、morph targets 和 Draco/Meshopt/BasisU 压缩扩展拒绝加载；模型文件和标注的持久化、授权访问、上传及版本管理属于宿主。

HTML 文字和 SVG 引线使用三维位置投影，保持文字正向；射线与模型几何相交判断遮挡。裁剪范围外的锚点不显示；标签按选中优先次序尝试分散，密集场景通过侧栏定位查看。法向量使用 normal matrix 处理非均匀缩放。

## 生命周期

浏览器渲染器在 Vue mounted 时创建，包导入不创建浏览器对象。来源改变时清空旧场景并取消请求，版本号排除过期加载；解析后发现过期的场景立即释放。卸载取消动画循环、观察器与控件并释放几何、材质、纹理和渲染器。

相机变化和容器 resize 标记画面需要更新；动画循环更新带阻尼控件，仅在需要时渲染和投影。编辑模式可写数据；present 模式同时隐藏写操作并在处理函数中阻止写入，切换模式或来源取消待提交草稿。

## 构建与验证

Vite 输出 ES/UMD 和独立 CSS，随后 vue-tsc 输出声明。`tsconfig.build.json` 排除示例，构建不复制 public 资产。包声明 CSS 入口并保留 CSS 副作用。

Playwright 从公开消费者示例验证行为。`scripts/check-package.mjs` 安装实际 tarball 到临时 Vue 消费项目，再检查模块导入、类型、生产构建和浏览器功能。CI 执行相同流程，验证源码开发之外的接入路径。
