# 三维模型教学标注组件规格

状态：用户已确认使用范围、验收入口和六项任务拆分；实现与接入文档已完成，见 [验收记录](./validation.md)。

## Problem Statement

开发者希望用 Vue 组件快速在网页中嵌入三维教学展示画布，让教师导入模型、标注具体部位并向学生讲解。现有组件主要面向固定学科示例或内部教学资源格式，没有完整的模型表面标注流程，样式与发布产物也尚未满足独立接入要求。

## Solution

新增以 A 原型为设计参考的教学展示组件：模型画布配合标注侧栏，侧栏可隐藏。教师在编辑模式中点击模型表面创建标注，通过侧栏修改或删除；课堂展示模式保留模型观察、标注选择和说明，禁止增删改。

首版支持静态、未压缩 GLB，来源可以是 URL 或本地文件。三维标注由模型表面锚点、引线和保持可读的文字组成。开发者通过 Vue 输入、双向绑定与事件传入和获取模型及标注数据，并在自己的系统中保存和恢复。

先完成组件功能与验收，再依据最终实现完善开发者示例、根目录 README 和开源贡献说明。

## User Stories

1. 作为网页开发者，我希望通过一个 Vue 组件嵌入模型画布，以便快速添加教学展示能力。
2. 作为网页开发者，我希望通过 URL 指定 GLB，以便展示系统已有的模型资源。
3. 作为教师，我希望选择本地 GLB 文件，以便准备自己的课堂模型。
4. 作为教师，我希望导入后自动获得完整模型视角，以便无需先调整相机。
5. 作为教师，我希望拖动旋转、缩放模型，以便从不同方向讲解结构。
6. 作为教师，我希望重置观察视角，以便快速恢复整体观察。
7. 作为教师，我希望点击模型表面放置标注锚点，以便准确指向讲解部位。
8. 作为教师，我希望为标注填写名称与说明，以便传达课堂讲解内容。
9. 作为教师，我希望取消正在创建的标注，以便重新选择部位。
10. 作为教师，我希望拖动旋转和点击空白时不会误建标注，以便自然地操作画布。
11. 作为教师，我希望在侧栏查看全部标注，以便管理课程讲解内容。
12. 作为教师，我希望选择侧栏条目后找到对应部位，以便查看被遮挡的标注。
13. 作为教师，我希望修改标注名称与说明，以便调整教学内容。
14. 作为教师，我希望删除不再需要的标注，以便保持模型展示清晰。
15. 作为教师，我希望旋转后锚点仍指向原有部位，以便保持讲解关联正确。
16. 作为学生，我希望标注文字保持正向可读，以便理解模型上的说明。
17. 作为学生，我希望引线明确指向模型部位，以便区分相邻标注。
18. 作为教师，我希望被模型遮挡的标注默认隐藏，以便减少空间关系混淆。
19. 作为教师，我希望可以淡化显示被遮挡的标注，以便比较前后结构。
20. 作为教师，我希望进入课堂展示模式后仍可旋转模型、选择标注并查看说明，以便持续讲解。
21. 作为教师，我希望课堂展示模式禁止创建、修改和删除标注，以便避免演示时误改。
22. 作为网页开发者，我希望能够隐藏侧栏，以便将画布嵌入自己已有的页面布局。
23. 作为网页开发者，我希望传入已有标注，以便恢复之前准备的课程内容。
24. 作为网页开发者，我希望获取标注变化与选择事件，以便保存数据并连接页面其他内容。
25. 作为网页开发者，我希望组件不直接修改传入的数据对象，以便保持宿主状态管理可靠。
26. 作为网页开发者，我希望模型和锚点使用稳定标识，以便同一模型换 URL 或重新载入后仍能恢复标注。
27. 作为教师，我希望更换模型后不会看到旧模型的标注，以便避免讲解错误。
28. 作为教师，我希望看见明确的加载、空场景和错误提示，以便知道模型是否可用。
29. 作为网页开发者，我希望快速切换来源时只有最新模型生效，以便正确响应页面操作。
30. 作为网页开发者，我希望组件在不同容器宽度下可以操作，以便用于不同网页布局。
31. 作为网页开发者，我希望组件样式不依赖原项目的全局变量，以便在新项目中直接使用。
32. 作为网页开发者，我希望通过 npm 安装产物获得可用的组件、样式和类型，以便正常开发与构建。
33. 作为新使用者，我希望 README 中的示例经过实际安装验证，以便按步骤完成首次接入。
34. 作为开源贡献者，我希望知道本地运行、验证与贡献方式，以便协助维护组件。

## Implementation Decisions

### 公开模块与接入约定

- 新增主要公开组件，暂定名称为 `ModelAnnotationViewer`。内部渲染细节由该模块封装，消费者通过公开 Vue 输入、双向绑定和事件使用。
- 现有公开导出保持可用；本轮围绕新教学展示流程实现，不扩大到旧学科场景或教学播放器的整体重构。
- 模型描述包含调用方提供的稳定模型 ID 与来源。来源接受 URL 或浏览器 File；组件的本地导入操作使宿主能获取新的模型描述。
- 标注支持传入已有集合与获取变更后的集合，适合通过命名 v-model 接入。组件提供未绑定外部状态时的内存编辑能力，实际持久化由宿主系统负责。
- 编辑与课堂展示使用 `edit`、`present` 两种模式，默认进入编辑模式。侧栏默认显示，允许隐藏。
- 对外提供模型加载完成、错误、标注选择和数据变更通知。错误应能区分来源不可用、格式不支持和标注数据无效等情形。

### 模型与锚点

- 首版导入范围为静态、未压缩 GLB。对格式不支持和加载失败给出明确提示，不用无关示例模型替代失败资源。
- 本地 GLB 需内嵌所需资源；URL 来源及相关资源需允许浏览器访问。组件管理自身创建的临时对象 URL 生命周期。
- 锚点保存网格局部坐标与局部法向量，通过当前网格变换投影到展示空间。法向量变换应处理非均匀缩放。
- 标注数据包含唯一标注 ID、模型 ID、稳定网格路径、局部位置、局部法向量、名称和说明，使用可序列化的数据值。
- 使用稳定网格路径关联部位，避免依赖名称唯一性、运行时 UUID 或文件名。相同模型结构重新加载后应能找到同一网格。
- 调用方应为同一模型使用稳定 ID；模型结构变化时更换 ID。首版不迁移不同版本模型之间的锚点。
- 非法坐标、重复标注 ID、无效网格引用和跨模型数据应有可解释的处理结果，组件不修改原始输入对象。
- 模型更换或清空时清理当前展示和待创建状态；旧模型标注不得出现在新模型上。最新加载请求生效，过期结果应释放。

### A 布局与交互

- 正式布局采用标注侧栏加模型画布。侧栏包含标注列表、名称和说明编辑、添加及删除操作。
- 创建流程为进入添加状态、点击可见模型表面、填写内容、确认或取消。拖动和点击空白不创建锚点。
- 在列表或画布中选择标注时显示对应说明；列表选择支持获得适合观察锚点的视角。隐藏侧栏后画布标注仍可选择与查看说明。
- `present` 模式允许观察、选择、重置视角和显示偏好调整，禁止标注创建、修改和删除。切换模式应取消未完成的编辑操作。
- 侧栏可隐藏；窄容器下应通过折叠或纵向布局继续提供编辑能力。390px 宽度下不出现横向溢出。
- 名称与说明作为文本显示，不作为 HTML 执行。
- 数据保存与恢复通过公开输入和事件接入；开发者示例演示 JSON 序列化及回填。

### 可读标注与运行可靠性

- 锚点指向三维模型部位；引线和文字通过投影呈现，文字保持正向可读。
- 根据实际模型几何检查遮挡，默认隐藏被遮挡的标注，并允许改为淡化显示。
- 标签尽量分散，选中标签优先保持可辨识。密集场景可通过侧栏选择并观察单个部位；首版不承诺任意密度下完全无重叠。
- 超出可见画布或相机裁剪范围的锚点不产生误导性可点击标签。
- 根据模型尺寸自动取景，根据容器尺寸调整投影和画布；显示内容应在相机、模型、标注或容器变化后更新。
- 重复加载、挂载与卸载应释放相应几何、材质、纹理、控件、观察器、临时 URL 和动画循环。
- 空模型、无有效网格、加载中、加载失败和 WebGL 不可用时都有可操作的反馈。

### 包与文档交付

- 提供独立默认样式和公开样式导入入口，公开组件不依赖原产品的 CSS 变量或布局类。
- 构建产物包含声明、组件 JavaScript 和样式；所有声明的包导出均对应实际产物。
- 用打包后的 npm 产物安装到独立 Vue 消费项目，验证渲染、样式、类型检查和生产构建。
- 原型保留为方案与交互决策的 primary source；正式源码与发布产物使用正式实现。
- 组件功能与接入验证完成后，再更新根目录 README、开发者示例及贡献说明。根目录 README 应明确安装、样式引入、最小示例、输入与事件、编辑和展示、数据保存恢复、模型范围及浏览器限制。

## Testing Decisions

- **主要验收入口：公开 Vue 输入、双向绑定和事件，配合真实浏览器的 canvas 交互。** 测试从消费者角度挂载组件，传入模型或标注、操作画布和侧栏，检查展示结果及对外事件。
- 仓库当前没有正式自动化测试套件。已有 prior art 是原型的真实浏览器验证：表面点击、锚点随观察视角变化、遮挡、数据回填、模型导入与布局切换。
- 测试应覆盖完整用户行为，不依赖 Three.js 私有字段、内部方法调用顺序或逐像素截图一致性。
- 验证 URL 与本地 GLB、自动取景、空来源、清空、加载失败、不支持的来源，以及快速切换时旧结果不生效。
- 验证创建、取消、编辑、删除、列表与画布选择、输入对象保持不变、事件数据可序列化、同一模型重载后的恢复，以及跨模型和非法数据的处理。
- 验证观察视角变化时锚点关联不变、背面默认隐藏与淡化选项、画布裁剪、缩放和容器尺寸变化。
- 验证 `present` 模式无法触发标注增删改，切换模式取消未完成操作；隐藏侧栏仍可观察与选择；窄容器仍能完成编辑。
- 资源释放通过代码审查及浏览器中重复挂载、卸载和模型切换检查验证；卸载后没有迟到的加载事件或仍生效的动画操作。
- 发布接入以 npm 打包安装后的独立 Vue 项目验证，包含样式、类型声明与生产构建；源码开发服务器可用不能代替这一步。
- 保持类型检查、构建及相应行为测试通过。测试随各个可验收任务实现，不先铺设只验证内部实现的测试。

## Out of Scope

- glTF 多文件目录、OBJ、FBX、STL 等其他模型格式，以及 Draco、Meshopt、KTX2 等压缩或转码扩展。
- 骨骼、变形及模型自带动画播放，动画模型表面随动标注。
- 立体文字网格、圈选区域、自由绘制箭头、测量或模型几何编辑。
- B/C 布局、自动教学步骤播放、旁白或音频生成。
- 后端资源生成、账户认证、云端保存、多人协作和模型跨版本标注迁移。
- 任意场景复杂度与标注密度下的性能保证。
- 医学教学内容与示意心脏模型的专业精度验收。
- 实际 npm 发布操作；本轮交付先完成可安装、可验证的发布产物。
