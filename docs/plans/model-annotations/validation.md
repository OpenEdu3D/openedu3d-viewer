# 实现与验收记录

2026-09-17，正式实现位于 `feat/model-annotations`。已批准范围采用 A 侧栏布局：URL / File 静态未压缩 GLB、表面锚点与文字引线、标注创建/修改/删除、edit / present、可隐藏侧栏及容器响应布局。

## 验收入口

消费者通过公开 Vue 输入、命名 v-model 和事件接入，浏览器操作真实 canvas。测试不读取 Three.js 私有字段。示例恢复的数据被冻结，用于发现组件直接修改宿主对象的行为。

- URL 和本地 GLB、自动取景、加载/空场景/HTTP 失败、错误文件、动画与压缩拒绝、无有效网格、WebGL 不可用、本地外链资源提示。
- 表面创建、名称与说明修改、删除、选择与定位、取消、拖动返回起点与空白点击防误建。
- JSON 恢复、重复/跨模型/无效引用/零法向量过滤、输入不变、同一模型清空后重载恢复。
- 只读展示禁止组件写入、切换模式取消草稿、隐藏侧栏仍可查看说明、桌面网页 390px 容器仍能编辑且没有横向溢出。
- 旋转保持数据锚点、几何遮挡默认隐藏与 fade 偏好；缩放更新标签，平移出界隐藏，重置恢复。
- 最新来源生效、取消旧请求、卸载后没有迟到加载事件、重新挂载可加载。

从官方 npm registry 按 lockfile 完成干净安装，`npm run type-check` 通过。浏览器测试使用 Chromium；其他现代浏览器的自动化兼容验收尚未执行。

## 独立安装

`npm run check:package` 构建 JS/CSS 和声明，生成实际 tarball，再安装到临时的独立 Vue / Vite 项目。已通过 ESM/CJS 的无 DOM 导入、消费者类型检查、生产构建、公开 CSS、WebGL 渲染、标注绑定和课堂展示。

脚本直接提取 README 中的完整 Vue 示例，纳入消费者类型检查，并对最小示例执行生产构建后的真实创建操作。该检查覆盖正式安装入口，不使用源码别名或链接代替 tarball。

Vite 对包含 Three.js 的消费者 bundle 提示超过默认 500kB 阈值；生产构建成功。按需加载可以由宿主应用按页面需求处理。
