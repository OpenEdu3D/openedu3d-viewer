# 03：用 A 侧栏编辑并切换课堂展示

**What to build:** 教师通过 A 侧栏管理标注，在编辑与课堂展示之间切换；开发者可以隐藏侧栏，窄屏仍可操作。

**Blocked by:** 02：在模型表面创建并恢复三维标注。

**Status:** complete

**GitHub:** https://github.com/OpenEdu3D/openedu3d-viewer/issues/5

- [x] A 侧栏显示完整标注列表，支持选择、修改名称和说明、删除标注。
- [x] 列表选择关联对应模型部位与说明，并能获得适合观察锚点的视角。
- [x] 修改和删除通过公开数据绑定通知宿主，保持传入对象不被直接修改。
- [x] 默认编辑模式允许增删改，课堂展示模式保留观察、选择和说明并禁止增删改。
- [x] 切换至课堂展示时取消尚未完成的创建或编辑，无法提交迟到的写入。
- [x] 侧栏可隐藏；画布仍支持选择标注、查看说明和观察模型。
- [x] 窄屏通过折叠或纵向布局保持编辑能力；390px 宽度下无横向溢出。
- [x] 文字按文本呈现；验证编辑、删除、只读模式、侧栏隐藏和窄屏操作的完整行为。
