# 04：旋转与遮挡时保持标注可读

**What to build:** 教师从不同方向观察模型时，锚点与引线保持位置对应，文字可读；背面标注可隐藏或淡化，选中标注保持可辨识。

**Blocked by:** 02：在模型表面创建并恢复三维标注。可与任务 03 分别推进。

**Status:** ready-for-agent

**GitHub:** https://github.com/OpenEdu3D/openedu3d-viewer/issues/6

- [ ] 观察视角变化、缩放、容器尺寸变化后，锚点仍对应原部位，文字保持正向可读。
- [ ] 正确处理网格变换和非均匀缩放，不改变保存的局部锚点。
- [ ] 根据实际模型几何判断遮挡，默认隐藏被遮挡标注，可淡化显示。
- [ ] 超出画布或相机裁剪范围的锚点不会出现误导性可点击标签。
- [ ] 多个标签尽量分散，选中标签优先可辨识；不承诺任意密度下完全自动避让。
- [ ] 显示偏好调整在课堂展示模式也可用，并能通过公开输入控制。
- [ ] 验证前后视角、遮挡偏好、画布边界、缩放及容器变化时的用户可见行为。
