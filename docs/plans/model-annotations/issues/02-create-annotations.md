# 02：在模型表面创建并恢复三维标注

**What to build:** 教师点击模型表面创建名称和说明，开发者通过公开数据绑定获取标注、序列化保存，并在同一模型重新加载后恢复。

**Blocked by:** 01：嵌入组件并导入静态 GLB。

**Status:** ready-for-agent

**GitHub:** https://github.com/OpenEdu3D/openedu3d-viewer/issues/4

- [ ] 公开标注数据包含唯一 ID、模型 ID、稳定网格路径、局部位置与法向量、名称和说明。
- [ ] 添加流程支持选取表面、填写内容、确认和取消；拖动与点击空白不会误建标注。
- [ ] 创建后在画布显示锚点、引线和正向可读的文字，标注可选择并向宿主通知。
- [ ] 支持传入标注及获取新集合；输入对象不被直接修改，事件数据可 JSON 序列化。
- [ ] 支持无外部绑定时的内存使用，以及绑定宿主数据时的保存和回填。
- [ ] 同一模型重新加载或 URL 改变后能够恢复原网格上的锚点，模型身份独立于文件名与 URL。
- [ ] 跨模型标注、重复 ID、非法坐标和失效网格引用不会被错误显示，并有可解释的反馈。
- [ ] 接入示例可以演示创建、获取、保存与恢复；通过公开组件入口验证这些行为。
